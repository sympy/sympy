# Instructions for AI agents

## Opening pull requests

When opening a PR for this repo (sympy/sympy), always account for AI usage as
required by `.github/PULL_REQUEST_TEMPLATE.md` and sympy's
[Policy on AI Generated Code](doc/src/contributing/ai-generated-code-policy.rst):

- **Prefer user written pull request descriptions and comments.** And in any
  instance where you (the AI agent) does write a pull request description or a
  comment to a pull request or issue, you must disclose in the text that it
  was written by an AI agent. Pull requests that are opened with entirely
  AI-written descriptions are more likely to be closed outright.

- **The `#### AI Generation Disclosure` section of the PR template is
  required.** It must disclose the tool or agent used (and the model) and
  specify which files or line ranges were AI-generated. Disclosure is not
  required for minor assistive tasks such as spell-checking or code review in
  primarily human-authored work — but if in doubt, disclose. As noted in the
  previous point, it is preferred if the human user writes the pull request
  description, but in any instance where you, the AI agent, fills it out, this
  section must be included.

- **All code must be reviewed by a human.** The human who opens the pull
  request is responsible for all code, whether it was written by a human or by
  an AI agent.

- **If an entire commit is generated by AI, this should specified in the
  commit message.** A Co-Authored-By line is sufficient. Do not include links
  to Claude Code sessions in commit messages.

## Coding Guidelines

- Do not add comments to code or tests unless the comments are genuinely
  important to the code. Comments should never reference previous code
  behavior. Notes about previous code behavior belong in commit messages and
  pull request comments, not in code comments.

- Do not silence exceptions. SymPy is a library. It is preferred for
  exceptions to be bubbled up to the caller with their full tracebacks.
  Silenced exceptions

- Ensure all code quality checks pass before committing. Code quality checks
  can be run with `python bin/test quality` and `ruff check sympy`.
