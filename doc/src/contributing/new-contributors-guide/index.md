# Guide for New Contributors

```{admonition} Google Summer of Code 2027
:class: note

SymPy will not participate in [Google Summer of Code
(GSoC)](https://summerofcode.withgoogle.com/) 2027 unless we find a way to
manage the large volume of pull requests we have been receiving. If you are
contributing to SymPy primarily to prepare a GSoC application, please be aware
it is likely we will not participate in GSoC.
```

This guide goes over how to contribute code to SymPy for new contributors.
It is split into sections based on how experienced you are with open source.

Please first read our **[](../introduction-to-contributing.md)** which 
contains important non-technical advice on how to contribute. It's 
probably the most important part of our guide so please do not 
skip it. We get a lot of low-quality spam pull requests because people jump
straight into contributing without first trying to understand SymPy's culture.

After reading the introduction, skip to the section that 
matches your level of experience. If you have never contributed to an open
source project before, start with **[](./dev-setup.md)**. If you are already
familiar with the basics of how to use git and GitHub, but you have never
contributed to SymPy before, start with **[](./workflow-process.md)**.
